# DO NOT USE THESE RESULTS

The file `ts_backtest_2024_20260213_235745.json` in this directory reports R²=0.996
across all positions and weeks. This is implausible (realistic ceiling: 0.2–0.4).

Root cause: Generated by an older `TimeSeriesBacktester.leakage_safe_features()` that
computed rolling features from a combined train+test window, contaminating train-period
stats with future data. The backtester was fixed; these results reflect a leaky pipeline.

Do not use as a baseline. Do not cite in experiment logs.
