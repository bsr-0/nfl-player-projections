How to read this. "Predicted margin" is home score minus away score (positive = home favored, same convention as "Market spread"). "Home win prob." is this model's probability the home team wins outright. Both are shown next to the market's own number so you can see how closely -- or not -- the model tracks the closing line.

Does this beat the market? Mostly no, and this page says so rather than implying otherwise. Measured on a proper walk-forward backtest (train only on seasons strictly before the ones being scored -- see src/evaluation/game_outcome_backtester.py / game_margin_backtester.py): —

Played games. Once a game kicks off, its row is the prediction as it was committed to this project's repository before kickoff, taken from the repository's history -- not re-run afterwards (the saved models were trained on all history, so a re-run would have seen the game). The market spread and total shown are the ones that row was published against. Final games add the score and whether each call was right: the winner (for the chosen win/loss model), the spread pick and the over/under pick (for the chosen margin/total model). Games with no prediction committed before kickoff are listed in the track record, never filled in later.
